# LEX — демонстрация интерфейса ПСБ Hack&Change 2026

Это временное публичное размещение визуального демо LEX в ранее пустом репозитории. **Здесь только интерактивный интерфейс с демонстрационными ответами, не реальный DeepSeek.**

Полный Python/FastAPI backend и проект готовы в ZIP, передаваемом в чате. Для запуска с DeepSeek нужен сервер и переменная окружения `DEEPSEEK_API_KEY`; никогда не помещайте ключ в GitHub.

## Безопасная настройка ключа

- Локально: `.env` (не коммитить).
- Vercel: Project → Settings → Environment Variables → `DEEPSEEK_API_KEY`.
- Render: Web service → Environment → `DEEPSEEK_API_KEY`.

### Ограничения

GitHub Pages — статический хостинг и не запускает FastAPI. Интерактивное демо предназначено для просмотра дизайна; реальные юридические ответы требуют развёрнутого backend.
